### Génération Prisma hors réseau et build

Le CLI tentait de télécharger le moteur natif de migration dès la génération.
Le client a été généré par le compilateur WASM fourni dans Prisma 7.10.0, avec
un préchargement **local temporaire, non committé** supprimant uniquement ce
téléchargement anticipé :

```javascript
const Module = require('node:module');
const original = Module._load;
Module._load = function(name, ...args) {
  const result = original.call(this, name, ...args);
  if (name === '@prisma/engines') {
    return { ...result, ensureNeededBinariesExist: async () => {} };
  }
  return result;
};
```

```bash
NODE_OPTIONS=--require=/tmp/a03-prisma-offline.cjs npm run build
```

Le build a réellement généré le client, vérifié les types et produit
`dist/server.js`, `dist/create-superowner.js` et `dist/privacy-storage.js`.
Ce mécanisme ne remplace aucun moteur pour les migrations et ne contourne pas
la politique réseau. La CI et la procédure standard continuent à utiliser
`npm ci`, `prisma generate` et `prisma migrate deploy` normalement.
